# 03. 前端界面与交互设计

本文档定义**普通高频流程如何走短路径、异常与受限事实放在哪里提示、引导用户作出什么决定，以及前端状态归属**。关于取消、翻页、并发冲突判定与迁移五态结果的权威规则，统一遵循 [02-database-engine-design.md](./02-database-engine-design.md)，本文件不重复定义底层语义。

---

## 1. 交互原则：高频操作走短路径

1. **零多余点击的高频路径**：
   - 双击对象树中的表 → 直接打开数据浏览标签页；
   - 在 SQL 编辑器按 `Ctrl+Enter` → 直接在下方显示结果网格；
   - 普通查询成功**绝不弹窗打扰**，仅在底部状态栏静默刷新耗时与行数；
   - SQL 变更预览、参数绑定表与执行明细默认收起，**按需展开**。
2. **上下文始终可辨**：
   - 顶部上下文条与 Tab 标题始终清晰显示“当前连接（含环境色标：红=生产 / 琥珀=测试 / 绿=开发）→ 目标库 / Schema”，避免看错库误操作。
3. **会改变下一步决定的事实，直接放在操作旁**：
   - 某张表不能改删、或仅支持新增、或不支持整批事务提交时，**直接在网格工具栏旁给出简明原因**，不等用户点保存才报错；
   - 改表计划不能整体回滚（如 MySQL 隐式提交）时，在点击“应用”前的确认区直接明示边界；
   - 一旦发生会话丢失、提交结果未知或改表确认丢失，直接给出清晰下一步动作（“重新连接”或“先刷新核对数据/结构”），绝不诱导盲目重试。
4. **四库语义一致、按能力裁剪**：
   - PG / MySQL / MariaDB / SQLite 共用相同的按钮图标与含义；
   - 数据库不支持的对象类型（如 SQLite 的 Schema / 序列）直接不出现在对象树，前端不散落“按库名/版本号 `if/else`”的硬编码，全部消费后端返回的 `Capabilities` 与 `TableEditability`。

## 2. 主工作台布局（自建轻量多标签工作台）

```text
+----------------------------------------------------------------------------------+
| [连接+] [新建查询]  |  prod-pg (红标) / app_db / public  |  [快速跳转 Ctrl+K] [⚙] |
+----------------------+-----------------------------------------------------------+
| [对象浏览器] [过滤]   | [Query 1] [users (实时浏览)]                              |
|----------------------|-----------------------------------------------------------|
| ▼ prod-pg (PG 16)    |  1 | SELECT u.id, u.name, o.total                        |
|   ▼ app_db           |  2 | FROM users u                                         |
|     ▼ public         |  3 | JOIN orders o ON o.user_id = u.id                    |
|       • users        |  4 | WHERE u.status = 'active';                           |
|       • orders       |-----------------------------------------------------------|
|       👁 v_users     | [▶ 运行 Ctrl+Enter] [▶▶ 全部运行] [■ 停止 (Esc)] [历史]   |
|       # order_seq    |-----------------------------------------------------------|
| ▶ local-mysql        | [结果 1] [执行明细]    [一次性快照] [< 第 1 页 >] [200/页] |
| ▶ dev.sqlite         | +----+----------+----------+----------------------------+ |
|                      | | id | name     | total    | created_at                 | |
|                      | | 1  | 张三     | 128.50   | 2026-11-24 10:12:00        | |
|                      | | 2  | 李四     | NULL     | 2026-11-24 11:05:31        | |
|                      | +----+----------+----------+----------------------------+ |
|                      | 选中值预览 / 选区统计 | [¶ 空白符] [查看全文] [复制] [导出] |
+----------------------+-----------------------------------------------------------+
```

- **高密度桌面风与可调字号**：数据网格严格单行（行高由 `useSettingsStore.densityMetrics` 统一管理，支持紧凑 `28px` / 标准 `31px` / 舒适 `34px` 三档缩放，`#` 行号列左吸顶固定、支持行/列双虚拟化滚动与采样自动列宽）；对象树展平后由 `@tanstack/vue-virtual` 虚拟滚动渲染；外观主题支持跟随系统 / 亮色 / 暗色。
- **切页不丢状态**：已打开的查询与表浏览标签使用 `v-show` 保活（目前不设后台标签淘汰上限，关闭标签时立即销毁释放内存），切换标签保留 CodeMirror 6 撤销历史、光标、选区、分屏比例与网格手动列宽，并在激活/失活时显式保存与恢复编辑器及网格的滚动位置；仅在查询标签正在运行或 SQL 相对初始/上次执行内容有未执行修改时，关闭标签或断开连接前弹出二次确认。
- **可滚动完整值浮窗（Value Inspector Modal）**：双击单元格（或选中按 `Space`）弹出独立纵向滚动的浮窗查看大文本、格式化 JSON 或按需流式查看/下载 BLOB，不挤占主表格横向空间；所有浮窗统一经 `BaseModal` 管理焦点进入、Tab 焦点陷阱与关闭后焦点恢复。

## 3. 前端状态归属（严格遵守“不自猜后端状态”）

| Pinia Store | 负责的状态（仅限 UI 态 + 后端确认状态镜像） |
| :--- | :--- |
| `useConnectionsStore` | 连接列表、在线态（`activeMap`）、并发连接去重与后端下发的 `Capabilities` |
| `useSchemaStore` | 左侧虚拟树已加载库/Schema/表对象与补全字典缓存，含在途请求去重及按连接代次/请求序号防乱序覆写 |
| `useWorkspaceStore` | 打开的 Tab、统一 Tab 修改 Actions、当前在途 `execID`、只读快照行（`markRaw`）、以及**后端权威回报的 `SessionState`**（前端严禁自行推断事务是否已结束） |
| `useUiStore` | 全局 Toast 通知与全部浮窗状态（连接/设置/DDL/值预览/快速跳转/二次确认框），统一管理 `Esc` 关闭层级栈 |
| `useSettingsStore` | 外观主题（跟随系统/亮色/暗色）、字号缩放与统一行高指标（`densityMetrics`）、侧栏宽度、默认页大小、不可见空白符显示开关 |
| `useGridEditStore`（Phase 2 规划） | 按 `tabId` 暂存的未提交草稿（增/改/删单元格）、Undo/Redo 栈、后端生成的同源 `ChangePlan` 预览数据 |
| `useTransferStore`（Phase 2+ 规划） | 后端事件推送的导入/导出进度与任务取消句柄 |

> `frontend/bindings/` 由 `wails3 generate bindings` 自动生成，禁止手改；`frontend/src/api/types.ts` 仅导出纯 DTO 类型/枚举与无状态 URL 工具，与 `frontend/src/api/client.ts`（懒加载 Wails RPC 绑定与统一 `AppError` 归一化）解耦。

## 4. 核心流程与异常决策落点

### 4.1 对象浏览与连接管理
- **连接配置**：支持 MySQL / PostgreSQL / MariaDB / SQLite 四引擎切换与测试连接；“只读模式”复选框旁明确注明：**此开关为客户端防误写护栏（SQLite 可本地只读打开），生产强只读请以数据库账号实际权限为准**。
- **对象树**：使用 `@tanstack/vue-virtual` 虚拟滚动渲染展平树，仅渲染驱动能力声明的对象层级；右键菜单提供实时浏览数据、查看表结构与 DDL、按当前方言生成模板新建查询、复制表名。

### 4.2 SQL 编辑器（CodeMirror 6）
- **日常短路径**：自动按当前连接加载 PG / MySQL / MariaDB / SQLite 方言高亮；打开标签、切换库/Schema 或在编辑器内执行 `USE` 切库后自动刷新补全字典；选中文本执行选中，未选中将光标位置转为 UTF-8 字节偏移交由后端 `sqlsplit.StatementAtCursor` 定位单条执行（`Ctrl+Enter`），`Ctrl+Shift+Enter` 执行全部。
- **高危 SQL 保护（后端单一事实来源）**：对生产色标（`red`）连接执行无 `WHERE` 的 `UPDATE`/`DELETE`、`DROP`、`TRUNCATE`（含 `EXPLAIN ANALYZE`、MariaDB `ANALYZE <DML>`、MySQL/MariaDB `/*! ... */` / `/*M! ... */` 可执行注释及 PostgreSQL `WITH d AS (DELETE ...)` 数据修改 CTE）时，由后端 `QueryService.ExecuteSQL` 在执行前对实际将运行的同一批解析语句做校验（读取连接安全配置失败时 fail-closed 中止执行），返回 `requiresConfirm`、命中语句及与具体语句绑定的 `confirmToken`；前端弹出 `ConfirmDialog`（默认聚焦取消按钮并锁定 Tab 焦点），用户明确确认后原样携带 `confirmToken` 重新发送，杜绝前后端切分不一致或令牌错配导致的绕过风险。
- **停止执行与三类异常的落点区分**（底层语义见 [02 第 2 节](./02-database-engine-design.md#2-权威规则一取消执行断线与重连internalsession)）：

| 后端确认状态 | 展示位置 | 给用户的明确下一步决策 |
| :--- | :--- | :--- |
| **语句已取消**（`ERR_STATEMENT_CANCELED`） | 结果区顶部温和信息条（不弹窗） | 说明“语句已取消，原会话存活”；若 PG 处于 `AliveFailedTx`，在信息条旁直接放置 **`[执行 ROLLBACK]`** 按钮。 |
| **原会话已丢失**（`ERR_SESSION_LOST`） | 编辑器顶部醒目橙色横幅 + 状态栏提示 | 明确说明“原连接已中断或停止复用，临时表与未提交事务已失效”，提供 **`[在新会话中重连]`** 按钮，由用户确认后继续。 |
| **提交结果未知**（`ERR_COMMIT_OUTCOME_UNKNOWN`） | 阻断式高危警示框 + 持久横幅 | 明确说明“`COMMIT` 已发出但确认丢失，无法判断是否已提交”，**不提供自动重试按钮**，引导用户先核对数据后再重建会话。 |

### 4.3 数据结果网格（自建轻量网格 + `@tanstack/vue-virtual` 行/列双虚拟化）
1. **翻页与状态提示**（底层语义见 [02 第 3.2 节](./02-database-engine-design.md#32-双路径翻页语义表浏览-vs-编辑器任意-sql)）：
   - **表浏览 Tab**：实时查库、按稳定键排序分页，支持顶部 `WHERE` 快捷筛选条与服务端列排序；
   - **编辑器结果 Tab**：从后端一次性快照切片翻页。触及容量上限时，在翻页条旁显示轻提示“仅预览前 N 行，如需全量请导出”；快照过期（`ERR_RESULT_EXPIRED`）时在翻页区直接给出 **`[重新执行 SQL]`** 按钮（绝不静默重跑）。
2. **单元格保真渲染、智能列宽与框选复制**：
   - 单元格统一由 `CellText` 渲染并保持简洁纯文字无胶囊排版：`NULL` 以纯灰色斜体显示、空串以无框淡灰 `""` 显示、有值内容一律使用主色；被后端截断的超长文本在单元格和预览栏显式标示 `截断` 徽标；底部提供「`¶ 空白符`」开关按需显示空格 `·` / 制表符 `→` / 换行 `↵` / 零宽字符（复制原文不混入可视化符号）；`BIGINT`/`DECIMAL` 按前 100 行采样自动扩宽（默认上限 `420px`）并支持双击分隔线 Auto-Fit；单击单元格在底栏预览完整值，双击弹出可滚动浮窗查看长文本/JSON/BLOB。
   - **导出边界诚实提示**：支持矩形框选复制为 TSV / CSV / JSON / SQL `INSERT`。`INSERT SQL` 按当前引擎方言引用表名与列名（PostgreSQL / SQLite 使用双引号 `"`，MySQL / MariaDB 使用反引号 `` ` ``；自定义 SQL 无表名时附带占位注释提示）；当导出范围包含截断文本、BLOB 十六进制预览，或使用 TSV（制表符/换行转空格）与 CSV/TSV（`NULL` 与 `""` 均输出为空）时，在菜单文案及复制后的 Toast 中明确提示边界，避免误认为无损导出。
3. **网格写入提示放在工具栏旁**（Phase 2 规划，底层判定见 [02 第 4 节](./02-database-engine-design.md#4-权威规则三网格写入与并发冲突检测internalchangeset)）：
   - 前端直接消费后端返回的 `TableEditability`：
     - **只读连接 / 无写权限**：锁定全部编辑入口，旁注“只读模式 / 无写权限”；
     - **无稳定唯一键（含 SQLite 仅隐式 `rowid` 表）**：允许点击 `[+ 新增行]`（若有写权限），锁定单元格修改与删行，旁注“无显式主键或非空唯一键，仅支持浏览与新增”；
     - **非事务存储引擎表（如 MySQL/MariaDB MyISAM）**：旁注“MyISAM 为非事务表，首版不支持整批回滚提交”，引导使用 SQL 编辑器操作；
     - **可编辑表**：改后单元格浅黄/绿/红着色，底部常驻 `已修改 N 处 | [撤销] [预览 SQL] [提交 Ctrl+S] [放弃]`；点击预览按需展开与执行 100% 同源的参数化 `ChangePlan`；若提交命中并发冲突（`ERR_CONCURRENCY_CONFLICT`），**保留草稿不清空**、高亮冲突行，引导用户刷新对比后再决定。

### 4.4 可视化表结构设计器（Phase 3 规划）
- 提供 **列 / 索引 / 外键 / 选项 / 触发器 / 改表计划** 6 个子页签。
- **确认前明示边界**（底层语义见 [02 第 5 节](./02-database-engine-design.md#5-权威规则四跨库改表计划与五态迁移报告)）：
  - 点击“保存应用”前，在确认面板清晰标注本次 `MigrationPlan` 的原子性级别（`可整体回滚` / `单条原子 ALTER` / `⚠️ 非事务多步，中途失败无法整体回滚`），SQLite 额外列出受影响的依赖视图与 `INSTEAD OF` 触发器清单；DDL 明细可一键展开审阅。
- **执行后五态清晰汇报**：
  - 全部成功时温和刷新表结构；
  - 若中途失败或中断，弹出 `MigrationReport` 面板，逐条以徽章区分 **`已生效` / `已回滚` / `确认失败` / `未执行` / `结果未知`**；
  - 一旦任一步为 **`结果未知`（`StepOutcomeUnknown`）**，**隐藏“重试”按钮**，置顶高亮 **`[刷新并核对当前表结构]`** 操作。

## 5. 快捷键规范（统一由 `composables/useShortcuts.ts` 管理）

通过 `composables/useShortcuts.ts` 单一全局监听分派，严格遵守“**有浮窗打开时 `Esc` 仅关闭最顶层浮窗，绝不误取消后台运行中的查询**”的优先级规则，将 `Mod` 在 Windows/Linux 映射为 `Ctrl`，在 macOS 自动映射为 `Cmd`：

| 快捷键 | 功能 | 当前状态 |
| :--- | :--- | :--- |
| `Esc` | 优先关闭最顶层浮窗；无浮窗时取消当前运行中的查询 | 已实现 |
| `Mod + .` | 取消当前运行中的查询 | 已实现 |
| `Mod + K` | 全局快速跳转（连接 / 表 / 视图 / 命令） | 已实现 |
| `Mod + N` | 当前连接下新建 SQL 查询 Tab | 已实现 |
| `Mod + W` | 关闭当前 Tab（含未清空/运行中 SQL 时二次确认） | 已实现 |
| `Mod + ,` | 打开偏好设置浮窗 | 已实现 |
| `F5` | 刷新当前实时表浏览标签页 | 已实现 |
| `Mod + Enter` | 执行选中 SQL / 光标所在单条 SQL | 已实现（CodeMirror） |
| `Mod + Shift + Enter` | 顺序执行编辑器内全部 SQL | 已实现（CodeMirror） |
| `Mod + C` / `Space` | 网格复制选中原文 / 浮窗查看完整单元格 | 已实现（DataGrid） |
| `Mod + Shift + F` | 格式化 SQL | 待规划 |
| `Mod + S` | 保存查询，或在网格/表设计器中触发提交 | Phase 2/3 规划 |
| `Mod + Shift + N` | 将选中单元格置为 `NULL` | Phase 2 规划 |
| `Mod + /` | 注释 / 取消注释当前行 | 待规划 |
